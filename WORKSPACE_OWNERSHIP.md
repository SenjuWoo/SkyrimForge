# Source ownership

This existing Git repository owns Skyrim Forge and its Skyrim skill pack. Active source is this root; VERSION.txt, skyrim_forge/version.py and Git tags identify its version. Preserve its public remote, MIT licence, release process and prior tags/backups. Historical folder names are not versions.

Game Data, installed tools, staging, saves, profiles and supplied references are separate read-only inputs unless deployment has been explicitly approved. Product ZIPs are runtime deliveries; ledgers and development reports stay in source or separate release evidence.

New work stays local/private until publication is requested. "Put it on GitHub" means public and MIT for original work by default, subject to third-party rights and platform terms; preserve existing licences and explicit choices. Generic publication uses the appropriate destination (normally Nexus Mods for Skyrim). A mod needing no compilation does not get a duplicate GitHub repository by default; add source hosting when requested or needed for development.
