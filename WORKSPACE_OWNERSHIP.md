# Source ownership

This Git repository owns Skyrim Forge and its 48-skill pack. Active source: 6.2.1, branch codex/cache-migration-6-2-1. Prior public source v6.2.0 and live last-good 6.1.1 remain recoverable in tags/releases/deployment backups. The historical folder name is not the version.

Live installation is resolved through SKYRIM_FORGE_ROOT and remains separate. Source writes follow this repository; approved live deployments have their own backups. Game Data, staging, saves and supplied reference tool folders remain read-only.
