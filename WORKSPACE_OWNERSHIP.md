# Source ownership

This Git repository is the single source owner of Skyrim Forge and its Skyrim
skill pack. The active source version is 6.1.1 (CURRENT.txt). The historical
checkout folder name is not the version and must not be renamed by installers.
Git tags retain last-known-good source; v6.1.0 is the prior public release.
The live deployment is resolved from SKYRIM_FORGE_ROOT and is distinct from
this development checkout. Installed game, staging, saves and references remain
read-only. Common compilers are owned by the Starter Bundle.
